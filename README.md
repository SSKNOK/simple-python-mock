## ツール概要
特定のポートで起動し、`GET`、`POST`、`DELETE`、`PUT`のメソッドで受け付けたリクエストに対してモックレスポンスを返却します。

<br>

## サービスを開発した背景
これまで、いくつかのシステム開発プロジェクトに携わらせていただきました。

その中でフロントエンドとバックエンドにそれぞれ別々のサービスが立ち上がっていてAPIを介してやりとりしたり、バックエンドに複数サービスが立ち上がっていてAPIでサービス間のやりとりをするといった構成をとるパターンを多く見ました。

そういったプロジェクトではほとんどの場合モックを用いて開発を行います。

その際に社内のセキュリティ的な制限であったり、ツールのクラウドにデータが保存されてしまう等の理由で既存のOSS等のモックサーバーが使えない場合があります。

もしくは既存の公開されたモックサーバーではプロジェクト特有の構成に対応できないなど。

上記のケースに対応していち早くモックサーバーを立てるための雛型として当ツールおよびそのソースを公開することとしました。

<br>

## 準備と利用方法
### 準備

- 起動ポート設定ファイル（`setting/port`）にツールを起動するポートを設定します。
```
8000
```

<br>

- レスポンス定義ファイル（`setting/responses.json`）にレスポンスの定義を設定します。サンプルの形式のように設定してください。
- `DEFAULT`のレスポンス定義を1つ必ず定義し、任意の数だけそのほかのサンプル定義を設定してください。

```json
{
    "sample": {
        "method": "GET",
        "path": "sample/(.*)/sample",
        "response": {
            "status": 200,
            "body": {
                "message": "sample",
                "nestMessage": {
                    "message": "OK"
                }
            }
        }
    },
    "DEFAULT": {
        "method": "DUMMY",
        "path": "DUMMY",
        "response": {
            "status": 500,
            "body": {
                "messsage": "Mock Server cannot find mock response."
            }
        }
    }
}
```

|項目|説明|
|--|--|
|`DEFAULT`|レスポンス定義は必ず末尾に残してください。このレスポンス定義はレスポンス定義ファイルのその他のレスポンス定義に合致しなかった時に返却されるレスポンスになります。`DEFAULT`のレスポンス定義の`method`と`path`に設定される値はダミーでかまいません。|
|`レスポンス定義名`|`DEFAULT`以外のレスポンス定義のルートのキー名（サンプルだと`sample`）は任意の値を設定してください。動作に影響しません。|
|`method`|対象のリクエストのHTTPメソッド（`GET`、`POST`、`DELETE`、`PUT`のいずれか）を設定してください。|
|`path`|対象のリクエストパスを設定してください。クエリパラメータをpathに含める場合は正規表現で記述してください。正規表現でリクエストパスとの一致を見るので`.*`を設定すれば全てのパスのリクエストをキャッチします。 例）`test/([0-9]{1-3})`|
|`response` > `status`|レスポンスのHTTPステータスを設定してください。|
|`response` > `body`|レスポンスボディを設定してください。|

<br>

### 起動
exeファイルを実行、もしくは、`main.py`のあるフォルダで下記コマンドを実行してください。

```
python main.py
```

# Tips
## 改修したソースのビルド化
`main.py`のあるフォルダで以下のコマンドを実行します。
```
pyinstaller main.py --onefile --icon=./icon/icon.ico
```
- 上記コマンドで`dist`フォルダ配下にexeファイルが生成されます。
- exeは起動ポート設定ファイルとレスポンス定義ファイルが格納された`setting`フォルダが同階層にいればどこでも動かすことができます。

## exeの動作するOS
- `pyinstaller`で固めたexeは`pyinstaller`を実行したOSと同じOS上でしか動きません。当ブランチに格納されたexeはwindows環境で生成した、windows用のexeです。
- Mac環境の方に配布する場合は事前にMac OSで`pyinstaller`でexe化したうえでそちらを配布してください。
